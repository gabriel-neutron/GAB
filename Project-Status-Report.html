What is GAB

GAB is a tool for one analyst. It reads documents, finds facts, and builds a graph of entities and relations. Each fact keeps a link to its source. AI agents can propose new facts, but a proposal only becomes a fact after the analyst promotes it. The tool has a map view and a graph view. Current stack: TypeScript, PostgreSQL/PostGIS, MinIO, React 19, MapLibre GL. Live case: mapping a Russian crude-oil export / sanctions-evasion chain.
