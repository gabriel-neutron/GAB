# Code of conduct

This project uses the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, accept criticism of your work, and do not harass a person. These rules
apply in the issues, the pull requests and each other space of the project.

## Report a problem

Use the private report of GitHub: open the **Security** tab of the repository, then **Report a
vulnerability**, and start the title with "Conduct". The maintainer reads each report and keeps it
confidential.
