# FigureCard

The one bright card on the dark ground: `figure` fill (Bone on Obsidian, inverted in the light theme) that holds the single finding a screen or a chapter is about.

- `radius-lg`, 24px padding, no shadow, no border.
- Eyebrow `caption` in `on-figure`; the finding in `heading` (36px); a `data` source line; at most one button, `on-figure` fill with `figure` text.
- One per screen or report chapter. Two figure cards side by side cancel each other.
- Never put an entity hue or `signal` as a fill here; the pulse dot is the only chromatic mark.
