# SiteHeader

The single top bar of every screen: wordmark, the views, search and the live state; no sidebar menu, no mega menu.

- Height `header-height` (56px), transparent on `background`, `divider` hairline below.
- Wordmark: `GAB` in `caption` style, `foreground`, 1.2px tracking. No logo file exists yet: the wordmark is plain type.
- Views: `body-sm` links, `muted-foreground`; the current view `foreground` on `surface-secondary`, `radius-sm`.
- Search field on the right with the `/` hint. A live pulse shows when extractions run.
