# GhostLink

A typographic link: `foreground` text on a 1px `border` underline that turns `foreground` on hover; no fill ever appears.

- Use for "read more", a source, a legal act, a jump to the graph or the map.
- Radius `radius-0`. An arrow `→` marks a link that leaves the current view.
- Inside report prose, the link keeps `body` size and the same underline.
